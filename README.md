# ระบบบริหารจัดการแบบประเมินความเสี่ยงเกษตรกร (นบก. 1-56) และรายงาน OCC
### Occupational Health & Safety Screening System for Agricultural Workers (NBK. 1-56 & OCC Reports)

ระบบเว็บแอปพลิเคชันฟูลสแตกเพื่อสนับสนุนการทำงานของเจ้าหน้าที่สาธารณสุข (รพ.สต., สสอ., สสจ.) และ อาสาสมัครสาธารณสุขประจำหมู่บ้าน (อสม.) ในการคัดกรอง เฝ้าระวังความเสี่ยงจากการใช้สารเคมีกำจัดศัตรูพืช การตรวจคัดกรองเอนไซม์โคลีนเอสเตอเรสในเลือด (Reactive Paper) และการประมวลผลรายงานราชการ OCC-นบ01 และ OCC-นบ02 อัตโนมัติ

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

| ส่วนของระบบ | เทคโนโลยีที่เลือกใช้ | รายละเอียด |
| :--- | :--- | :--- |
| **Frontend** | **Vue 3** (Composition API, `<script setup>`) | โครงสร้างคอมโพเนนต์ยืดหยุ่น ประสิทธิภาพสูง เร็วและเบา |
| **Language** | **TypeScript** | Type-safe ตรวจจับข้อผิดพลาดข้อมูลทางการแพทย์ตั้งแต่ช่วงพัฒนา |
| **Styling** | **Tailwind CSS** | Mobile-First Responsive รองรับหน้าจอมือถือ แท็บเล็ต และคอมพิวเตอร์ |
| **Backend** | **Go (Golang 1.22+)** + **Gin Web Framework** | ขนาดเล็ก กินแรมน้อย คอมไพล์เป็น Single Binary รวดเร็ว |
| **Database** | **SQLite (modernc.org/sqlite - Pure Go)** | ไม่ต้องติดตั้งฐานข้อมูลแยก พกพาง่าย เปิดโหมด WAL รันได้ทันที |
| **Visualization** | **Chart.js** | แสดงผลแผนภูมิความเสี่ยง (Donut) และสถิติผลเจาะเลือด (Bar Chart) |

## ✨ คุณสมบัติเด่นของระบบ (Key Features)

### 1. Mobile-First Wizard คัดกรอง 5 ขั้นตอน
- **ออกแบบเฉพาะสำหรับสมาร์ตโฟนและแท็บเล็ต**: มีแถบสถานะความคืบหน้า (Progress Bar) พร้อมปุ่มกดตรึงด้านล่าง (Sticky Bottom Action Bar) ที่กดได้ด้วยนิ้วโป้งมือเดียวขณะลงพื้นที่แปลงเกษตร
- **ระบบค้นหาประวัติเดิม (Citizen ID Lookup)**: พิมพ์เลขบัตรประชาชนครบ 13 หลัก ระบบจะดึงประวัติเดิมผ่าน REST API มาเติมให้อัตโนมัติ
- **ปุ่มสัมผัสขนาดใหญ่ (Large Touch Cards & Pills)**: ลดความผิดพลาดในการกรอกข้อมูลภาคสนาม

### 2. ระบบคำนวณคะแนนและ Risk Matrix อัตโนมัติ
- **คำนวณคะแนนพฤติกรรมเรียลไทม์**:
  - ส่วน A (ข้อ 9–17): พฤติกรรมเสี่ยง คิดคะแนนตรง ($1, 2, 3$ คะแนน)
  - ส่วน B (ข้อ 18–23): พฤติกรรมป้องกันความปลอดภัย คิดคะแนนสเกลกลับด้านอัตโนมัติ (ไม่ใช่ = $3$, บางครั้ง = $2$, ทุกครั้ง = $1$)
- **จับคู่เกณฑ์ Risk Matrix กรมควบคุมโรค**: ประมวลผลร่วมกับกลุ่มอาการผิดปกติ 3 กลุ่ม ตัดเกรดความเสี่ยงทันที 5 ระดับ (ต่ำ, ปานกลาง, ค่อนข้างสูง, สูง, สูงมาก)
- **แจ้งเตือนการตรวจเลือดทันที**: แจ้งเตือนและปลดล็อกสเต็ปเจาะเลือดเฉพาะเคสที่เข้าเกณฑ์ (กลุ่มเสี่ยงค่อนข้างสูงขึ้นไป)

### 3. ระบบบันทึกการตรวจคัดกรองทางโลหิตวิทยา (Cholinesterase)
- **คัดกรองข้อห้ามก่อนเจาะเลือด**: ระยะเวลาสัมผัสสารเคมีล่าสุด
- **Quick Chemical Tags**: ปุ่มลัดเลือกสารเคมีที่ใช้บ่อย (เช่น คลอร์ไพริฟอส, ไกลโฟเสต, อะบาเมกติน, ไซเพอร์เมทริน, พาราควอต)
- **บันทึกระดับผลแถบกระดาษทดสอบ Reactive Paper**: ปกติ, ปลอดภัย, มีความเสี่ยง, ไม่ปลอดภัย พร้อมระบบแจ้งเตือนกรณีต้องส่งพบแพทย์

### 4. ทะเบียนเกษตรกรและการส่งออกข้อมูล (Farmer Registry & Export)
- ค้นหาและคัดกรองตามชื่อ, เลขบัตร 13 หลัก, ที่อยู่ หรือระดับความเสี่ยง
- แสดงรายละเอียดผลประเมินรายบุคคล (Detail Modal)
- **Export Excel (CSV UTF-8 BOM)**: รองรับการเปิดด้วย Microsoft Excel ภาษาไทยไม่เป็นภาษาต่างดาว

### 5. ระบบรายงานสรุปผลงานราชการ (OCC-นบ01 / OCC-นบ02)
- **แบบ OCC-นบ01 (ระดับ รพ.สต.)**: สรุปยอดเกษตรกรที่ได้รับการคัดกรอง, กลุ่มเสี่ยงสูง, ผู้ที่ได้รับการเจาะเลือด และผลไม่ปลอดภัย
- **แบบ OCC-นบ02 (ระดับ สสจ.)**: สรุปผลงานภาพรวมระดับอำเภอและจังหวัด พร้อมอัตราความครอบคลุมการคัดกรอง
- **Print-Ready Support**: ซ่อนแถบเมนูและปรับหน้าเอกสารให้อัตโนมัติเมื่อกดสั่งพิมพ์ (`Ctrl + P`)

## 🚀 วิธีการติดตั้งและรันระบบ (Getting Started)

### ข้อกำหนดเบื้องต้น (Prerequisites)
- **Node.js**: เวอร์ชัน 18+ ขึ้นไป
- **Go (Golang)**: เวอร์ชัน 1.22+ ขึ้นไป

### 1. การรันในโหมดพัฒนา (Development Mode)

#### รันเซิร์ฟเวอร์ Backend (Go + SQLite)
```bash
cd backend
go run main.go
# Backend จะเริ่มต้นทำงานที่ http://localhost:8080
```
*(เมื่อรันครั้งแรก ระบบจะสร้างไฟล์ฐานข้อมูล `nbk_records.db` ขึ้นในโฟลเดอร์โดยอัตโนมัติ พร้อมข้อมูลตั้งต้นจำลอง)*

#### รันเซิร์ฟเวอร์ Frontend (Vue 3 + Vite)
```bash
cd frontend
npm install
npm run dev
# Frontend จะเริ่มต้นทำงานที่ http://localhost:5173
```

---

### 2. การคอมไพล์เพื่อส่งมอบให้ รพ.สต. (Standalone Single Binary)

สำหรับติดตั้งบนคอมพิวเตอร์ของหน่วยบริการปฐมภูมิที่ไม่มีอินเทอร์เน็ต สามารถ Build หน้า Frontend ให้กลายเป็น Static Assets แล้วให้ Go Backend นำไปเสิร์ฟเป็นไฟล์ `.exe` เดียว:

```bash
# 1. Build Vue 3 Assets
cd frontend
npm run build

# 2. Build Go Executable (Windows .exe)
cd ../backend
go build -ldflags="-s -w" -o nbk_system.exe main.go
```

เจ้าหน้าที่เพียงดับเบิลคลิก `nbk_system.exe` ฐานข้อมูล SQLite จะถูกสร้างและรันเซิร์ฟเวอร์พร้อมเปิดเบราว์เซอร์ใช้งานที่ `http://localhost:8080` ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมอื่นเพิ่มเติม

## 🔌 ข้อกำหนด API (REST Endpoints)

| Method | Endpoint | คำอธิบาย |
| :--- | :--- | :--- |
| `GET` | `/api/farmers/:citizen_id` | ดึงประวัติเกษตรกรเดิมจากเลขบัตร 13 หลัก |
| `POST` | `/api/assessments` | บันทึกแบบประเมิน นบก. 1-56 และคำนวณความเสี่ยง |
| `GET` | `/api/assessments` | ดึงรายการแบบประเมินทั้งหมด (รองรับ `q` และ `risk_level`) |
| `GET` | `/api/assessments/:id` | ดึงรายละเอียดแบบประเมินรายบุคคล |
| `DELETE` | `/api/assessments/:id` | ลบข้อมูลแบบประเมิน |
| `GET` | `/api/stats/dashboard` | สรุปสถิติ KPI และการกระจายตัวของความเสี่ยง/ผลเลือด |
| `GET` | `/api/reports/occ01` | ดึงสถิติสรุปแบบรายงานราชการ OCC-นบ01 (รพ.สต.) |
| `GET` | `/api/reports/occ02` | ดึงสถิติสรุปแบบรายงานราชการ OCC-นบ02 (สสจ.) |

## 📐 ตารางวิเคราะห์ความเสี่ยง (Risk Matrix Criteria)

การตัดเกรดระดับความเสี่ยงตามแบบประเมิน นบก. 1-56 อ้างอิงตารางเมทริกซ์มาตรฐานของ **สำนักโรคจากการประกอบอาชีพและสิ่งแวดล้อม กรมควบคุมโรค**:

| ระดับกลุ่มอาการที่พบ (ในรอบ 1 เดือน) | คะแนนพฤติกรรม 15 - 24 แต้ม | คะแนนพฤติกรรม 25 - 30 แต้ม | คะแนนพฤติกรรม 31 - 45 แต้ม |
| :--- | :---: | :---: | :---: |
| **ไม่มีอาการผิดปกติ** | มีความเสี่ยงต่ำ | มีความเสี่ยงปานกลาง | มีความเสี่ยงค่อนข้างสูง* |
| **อาการกลุ่มที่ 1** (ทางเดินหายใจ/ผิวหนัง) | มีความเสี่ยงปานกลาง | มีความเสี่ยงค่อนข้างสูง* | มีความเสี่ยงสูง* |
| **อาการกลุ่มที่ 2** (ประสาทส่วนปลาย/ทางเดินอาหาร) | มีความเสี่ยงค่อนข้างสูง* | มีความเสี่ยงสูง* | มีความเสี่ยงสูง* |
| **อาการกลุ่มที่ 3** (ประสาทส่วนกลาง/รุนแรง) | มีความเสี่ยงสูง* | มีความเสี่ยงสูง* | มีความเสี่ยงสูงมาก* |

> ⚠️ **หมายเหตุ:** เครื่องหมาย `*` หมายถึง กลุ่มเป้าหมายที่ **ต้องได้รับการเจาะเลือดตรวจคัดกรองระดับเอนไซม์โคลีนเอสเตอเรส (Reactive Paper)**
